# File_manager 文件整理器介绍

本命令行工具是刚学了一点 Python，一时兴起做的小东西，顺便用来了解一下做东西的大致流程。

此工具唯一的功能是把文件按照扩展名自动整理进不同文件夹，以及撤回任意批次的移动操作。它既可以独立运行（有提示页面），也支持命令行参数。

## 使用方法

### 方式一：在命令行工具中运行 Python 源文件

在源文件所在目录运行命令行，运行下列指令：

- 整理操作：`python file_manager.py move -s "要整理的文件夹路径"`
- 撤销操作：`python file_manager.py undo`

### 方式二：直接运行可执行文件或以无参数形式运行 Python 源文件

运行后，按照指示菜单进行操作即可。

## 说明

- 首次运行会生成配置文件 config.json（分类规则，可以自行配置）。
- 配置文件损坏时，会使用程序内置的分类规则。这部分内容写在 categories.py 模块中。
- 移动记录会写入日志 log.jsonl；撤销操作不会被记录。
- 整理前会显示计划并询问确认。
